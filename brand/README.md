# Duo Budget — Premium Duo Brand Kit V3.0

Identité visuelle de référence : **nuage + cœur** (deux formes entrelacées), dans l'esprit de la planche Premium Duo validée.

Palette : Nuit `#0F1C2E`, Signature `#5775E8`, Positif `#2BAA89`, Ambre `#E9A14E`, Fond `#F7F8FA`, Surface `#FFFFFF`.

- `svg/duo-logo-horizontal-{dark,white}.svg` : logos principaux.
- `svg/duo-mark-{blue,white,navy}.svg` : symboles seuls.
- `svg/duo-app-icon.svg` : source de l'icône de l'application.
- `svg/duo-adaptive-foreground.svg` : avant-plan Android.
- `svg/duo-splash.svg` : composition du lancement.
- `svg/duo-favicon.svg` : icône web.

**Sources vectorielles SVG** : les fichiers avec texte utilisent Inter avec repli Arial. Convertir les textes en tracés dans Figma au moment de verrouiller le logo de production.

**Attention** : ceci est une branche de branding ; elle ne remplace pas encore `assets/icon.png`, `assets/splash.png` ni `app.json`. Les exports PNG compatibles Expo sont disponibles dans le kit téléchargeable. La fusion/déploiement doivent être validés après tests.

**Avant publication** : effectuer des recherches d'antériorité/disponibilité de marque, contrôler l'unicité du symbole et tester les icônes iOS/Android. Ne jamais réutiliser les anciennes photos du couple.
